# 历史想法封存

这里保留过去探索的核心思路，作为研究过程记录。各路线的状态来自当时记录，不作为当前训练入口或性能结论。当前工作的 AgentFormer 与非注意力信息传递方案保留在根目录。

## 1. 回报分布与风险条件

问题：单一回报预测难以表达多峰结果，也难以区分期望收益与风险偏好。
思路：先用 diffusion critic 拟合条件回报分布，再将目标回报或风险信号用于轨迹生成。
历史状态：有独立原型；风险条件未完整接入默认流程，风险控制与策略收益没有得到充分验证。

## 2. Mode 一致性与 Team-Role VQ

问题：不同 agent 独立选择合理的协作模式，组合后仍可能出现分工冲突。
思路：从联合轨迹学习团队模式码，再由局部历史预测模式；后续将单个团队码扩展为一组角色码，作为轨迹扩散条件。
历史状态：曾有两版实现。码本活跃或重建改善不足以证明协作语义，完整部署收益未建立，现仅保留想法。

## 3. Local-Credit 条件

问题：团队回报不能直接说明每个 agent 的作用与行为质量。
思路：集中式 teacher 估计 importance 与 action quality，再蒸馏到只读取本地历史的 adapter，把预测 credit 输入去噪器。
历史状态：方案阶段。teacher 的敏感性不自动等于因果贡献，本地是否能预测这些信用信息尚未验证。

## 4. Copula 依赖建模

问题：局部轨迹分布拟合良好，并不保证联合计划相容。
思路有两种：一是以公共因子耦合各 agent 的基础噪声，同时保持各自噪声边缘；二是用集中式 CDF/Gaussian copula 对生成样本施加训练期依赖正则，执行仍使用私有噪声。
历史状态：理论分析与方案稿。两种执行制度不同；公共随机源不能提供队友私有信息，局部信息缺口也不能仅靠 copula 弥补。

## 5. 计划记忆与重规划

问题：频繁重规划可能改变分工，也增加 diffusion 调用成本。
思路：固定 h 步复用一条预测计划；进一步把剩余计划作为软条件，用集中动作评分训练局部修正，再由残差、计划年龄等信息决定是否重规划。
历史状态：固定 h 缓存曾有实现；计划记忆、链式协调与学习门控仍属提案。本路线现作为历史记录封存。

## 6. Bi-ST 潜空间规划

问题：直接生成长观察轨迹成本较高，模型内的队友想象也可能造成协同误差。
思路：将观察片段压缩为短潜序列，训练潜空间 diffusion，并在时间去噪分支上加入软门控协同残差，最后解码自己的观察轨迹以恢复动作。
历史状态：方案阶段，潜表示与协同分支尚无实现或正式实验。

## 历史诊断问题

曾检查 CTDE 下各主体想象的队友下一步动作，是否与队友根据自身观测生成的实际动作一致。它用于识别联合想象与执行之间的失配，本身不是一套策略改进方法。

另曾尝试直接接入一致性模型的少步采样调度器，但没有配套训练与调用入口；该孤立接口已随旧方案清理。
